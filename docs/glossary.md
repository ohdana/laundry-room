- Flat
A household.

- Card
A physical token, holds no money. Inserting it into a slot gives it power.

- Laundry room
Green or yellow. Has one card slot, one tap, appliances.

- Appliance
A powered consumer: washing machine, tumble dryer, fan.

- Cycle
One program run of a washer or a dryer. Ends as Completed or Interrupted.

- Session
Card in → card out.

- Usage record
Flat, room, appliance, start, end, outcome, kWh.

- Ledger
List of usage records.

- Tariff
CHF per kWh.

- Bill
Per-flat amount for the usage.
